# QVAC Private Journal - 100% On-Device

Private journaling with **QVAC SDK 0.19.1** running entirely on-device. No cloud, no data leaves your machine.

## SDK Version
**@qvac/sdk: 0.19.1**
Uses: `loadModel`, `embed`, `ragIngest`, `ragSearch`, `completion`

## What it does
Save private thoughts → embedded locally → stored via `ragIngest` → ask questions → `ragSearch` finds relevant entries → `completion` answers locally.

## Install
```bash
git clone https://github.com/iiinsanityy/qvac-private-journal.git
cd qvac-private-journal
