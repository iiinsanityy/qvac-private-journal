 # QVAC Private Journal - 100% On-Device

100% local private journal using QVAC SDK. No cloud, no Ollama, no API keys.

## SDK Version
**@qvac/sdk: 0.19.1**

Uses: `loadModel`, `embed`, `ragIngest`, `ragSearch`, `completion`

## Install
```bash
git clone https://github.com/iiinsanityy/qvac-private-journal.git
cd qvac-private-journal
npm install
